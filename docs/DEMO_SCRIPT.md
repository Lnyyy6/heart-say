# 3 分钟 Demo 脚本与录制清单

> 已录制：[heart-say-demo.mp4](../assets/demo/heart-say-demo.mp4)（2:55，1440×900，无旁白，右侧内嵌字幕卡；字幕见 [heart-say-demo.srt](../assets/demo/heart-say-demo.srt)）。
> 重新录制：确保 API/Web 已启动，运行 `python scripts/record_demo.py`。

目标：3 分钟内讲清“为什么做、怎么运作、安全怎么守、效果怎么验”。语速控制在每秒 4-5 个汉字，画面以 1440×900 浏览器窗口为主。

## 录制前

```bash
# 终端 1
PYTHONPATH=src .venv/bin/uvicorn app.api.main:app --port 8010

# 终端 2
cd app/web && npm run build && npm run start

# 浏览器打开 http://localhost:3000，清空 localStorage 或点“新对话”
```

- 确认 `/health` 返回 `kb_docs: 80`，`qdrant_mode: qdrant-embedded`。
- 不要使用真实姓名、学校、电话；演示输入均为虚构。
- 关闭通知；浏览器缩放 100%；隐藏书签栏。
- 预跑一次“多轮 + 引用”和“危机”路径，确认流式正常。
- 录屏工具：QuickTime / OBS；鼠标移动慢一点，点击后停 0.5 秒。

## 0:00–0:20 开场

画面：首页，鼠标停在标题。

口播：

> “这是心语，一个面向中国家庭的青少年心理教育陪伴助手。它不做诊断、不荐药，先共情，再给一个能走的小步；遇到危机，优先安全。”
>
> “技术上它是 Qwen2.5-7B + QLoRA SFT + DPO + RAG + LangGraph，完整代码和评测都在仓库里。”

## 0:20–1:20 多轮对话与检索引用

操作：

1. 点击第一条建议“最近孩子总说不想上学，我该怎么开口？”
2. 等流式结束，展开“4 则知识库参考”，滚动展示标题、来源、摘要。
3. 输入“我是不是该让她别复习了？”，回车。

口播：

> “先看一次真实的多轮对话。它先接住家长的焦虑，再给一个低门槛动作，最后用开放问题把话头留给对方。”
>
> “回答下方是知识库引用：不是‘模型觉得’，而是可追溯的片段、来源与相关度。第二轮它会记得上一轮的孩子初三、失眠背景，不会从头问起。”
>
> “右侧可以看到它记住的上下文，以及始终在线的危机资源。”

## 1:20–2:00 危机安全

操作：

1. 点左侧“新对话”。
2. 输入：“我已经决定今晚跳楼了，你别劝我，也别告诉任何人。”
3. 等安全提示和回复出现，鼠标依次停在 12356、120/110。

口播：

> “危机场景不交给模型自由发挥。它走固定协议：先确认当下安全，请对方离开危险地点、联系可信任的大人，提供 12356 和 120/110，并明确不承诺保密。”
>
> “这条路径不检索、不生成，避免在最需要稳定的时候出现不可控内容。跨轮追问也会继续保持风险状态，除非用户明确说已经安全。”

## 2:00–2:40 评测看板

操作：点左侧“评测”，停在四个指标，再滚到维度条与失败样本。

口播：

> “效果不是靠感觉。100 条中文对话用例，六个维度：共情、边界、安全、事实、人设、低说教感。”
>
> “RAG 让事实/引用维度提升 0.57，通过率从 99.0% 到 100%；代价是 P95 增加约 200 毫秒。我们没有为了引用覆盖率强挂引用，新增 boundary 节点后引用率从 81% 降到 61%，这是安全优先的取舍。”
>
> “50 条红队首轮只有 72%，修了 8 个真实漏洞和 6 个评审器误报后到 100%。完整的问题、修复和残余风险都写在安全报告里。”

## 2:40–3:00 收尾

画面：回到首页或仓库 README 的架构图。

口播：

> “这就是心语：不是让模型更像医生，而是让它知道什么时候该说、什么时候不该说、什么时候把人交给现实中的专业支持。”
>
> “温柔可以是风格，安全必须是结构。谢谢。”
